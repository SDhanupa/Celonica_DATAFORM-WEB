# Sample Workspace Skill

This is a template workspace skill for **ExportHub**. You can define project-specific coding guidelines, build commands, testing strategies, or domain-specific logic here.

## How to use workspace skills:
1. Place each skill in its own subdirectory inside [C:\xampp\htdocs\ExportHub\.agents\skills/](file:///C:/xampp/htdocs/ExportHub/.agents/skills/).
2. Every skill must contain a `SKILL.md` file with a YAML frontmatter containing `name` and `description`.
3. The model will automatically discover these skills and load them when their description aligns with the task.
